ФОНАРИК — Android-приложение

Что умеет:
- Одна кнопка включает и выключает светодиодную вспышку телефона.
- Показывает состояние ВКЛЮЧЕНО / ВЫКЛЮЧЕНО.
- Если на устройстве нет вспышки, кнопка будет недоступна.

Как получить APK:
1. Установите Android Studio на компьютер.
2. Распакуйте архив FonarikAndroid.zip.
3. В Android Studio выберите Open и откройте папку FonarikAndroid.
4. Дождитесь завершения Gradle Sync.
5. Выберите Build → Build Bundle(s) / APK(s) → Build APK(s).
6. APK будет создан в app/build/outputs/apk/debug/app-debug.apk.
7. Перенесите APK на телефон Android и установите. При необходимости разрешите установку приложений из этого источника.

Примечание:
В этой среде нет Android SDK и Gradle, поэтому готовый APK здесь собрать нельзя.
Проект содержит исходный код настоящего Android-приложения. Для управления вспышкой
используется системный CameraManager. На некоторых устройствах Android может запросить
разрешение камеры; это нужно для доступа к аппаратной вспышке.


БЕСПЛАТНАЯ СБОРКА ЧЕРЕЗ GITHUB ACTIONS:
1. Создайте бесплатный аккаунт на https://github.com (если его ещё нет).
2. Создайте новый репозиторий, например Fonarik.
3. Распакуйте архив и загрузите ВСЕ файлы и папки проекта в корень репозитория.
   Важно: загрузите также скрытую папку .github с workflow build-apk.yml.
4. Откройте вкладку Actions в репозитории.
5. Выберите workflow "Build Android APK" и нажмите Run workflow
   (если сборка не запустилась автоматически после загрузки).
6. После успешной сборки откройте завершённый запуск workflow.
7. Внизу страницы в разделе Artifacts скачайте Fonarik-debug-APK.zip.
8. Распакуйте его — внутри будет app-debug.apk. Перенесите APK на телефон и установите.

GitHub предоставляет бесплатные минуты Actions для публичных репозиториев;
для приватных репозиториев действуют лимиты бесплатного тарифа.
